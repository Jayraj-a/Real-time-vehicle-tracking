## 📌 About the Project

The **Real-Time Vehicle Tracking System** is a full-stack web application designed to provide centralized monitoring and management of vehicles and fleet operations.

The system combines a **React + Vite frontend** with a **Python backend** to provide vehicle management, driver management, live tracking, trip history, alerts, geofencing, analytics, reports, and real-time communication.

---

## 🎯 Project Objectives

* Provide real-time visibility of vehicles.
* Monitor vehicle locations and movement.
* Manage vehicle and driver information.
* Track trips and maintain trip history.
* Detect and manage vehicle-related alerts.
* Support geofencing-based monitoring.
* Provide fleet analytics and reports.
* Enable real-time communication between frontend and backend.
* Provide a modular architecture for future expansion.

---

# ✨ Key Features

### 📍 Live Vehicle Tracking

Monitor vehicle locations and movement through the tracking dashboard.

### 🚘 Vehicle Management

Manage and monitor vehicle information within the fleet.

### 👨‍✈️ Driver Management

Maintain driver information and associated fleet operations.

### 🛣️ Trip Management

Create, manage, and review trip-related information and history.

### 🔔 Alert Management

Monitor and manage alerts generated by the system.

### 🗺️ Geofencing

Create and manage geographical boundaries for vehicle monitoring.

### 📊 Analytics & Reports

Provide operational insights and reporting capabilities.

### 🔄 Real-Time Communication

WebSocket-based communication enables real-time data exchange.

### 🛰️ GPS Simulation

A GPS simulator is included for development and testing of location-based functionality.

# 🚀 Getting Started

## Prerequisites

Install the following:

* Git
* Python 3.x
* Node.js
* npm

Verify the installation:

```bash
git --version
python --version
node --version
npm --version
```

---

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Jayraj-a/Real-time-vehicle-tracking.git
```

```bash
cd Real-time-vehicle-tracking
```

---

## 2️⃣ Backend Setup

Navigate to the backend:

```bash
cd Backend
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```powershell
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## 3️⃣ Environment Configuration

Create a local:

```text
Backend/.env
```

file for environment-specific configuration.

> ⚠️ **Never upload `.env` to GitHub.**

Do not expose:

* API keys
* Passwords
* Database credentials
* Authentication secrets
* JWT secrets
* Private tokens

---

## 4️⃣ Frontend Setup

Open a new terminal and navigate to:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will display the local development URL in the terminal.

# 🔄 Git Workflow

For collaborative development, avoid making every change directly on `main`.

Create a feature branch:

```bash
git checkout -b feature/live-tracking
```

Make your changes:

```bash
git add .
```

Commit:

```bash
git commit -m "Add live tracking functionality"
```

Push:

```bash
git push -u origin feature/live-tracking
```

Then create a **Pull Request** on GitHub.

### Recommended Branch Naming

```text
feature/<feature-name>
fix/<issue-name>
docs/<documentation-name>
refactor/<module-name>
test/<test-name>
```

Examples:

```text
feature/live-tracking
feature/geofencing
feature/vehicle-management
fix/tracking-api
docs/update-readme
```

---

# 🔐 Security

The following files and directories should **not** be committed:

```text
.env
*.env
__pycache__/
*.pyc
venv/
.venv/
node_modules/
```

The repository contains a `.gitignore` file to prevent these generated or sensitive files from being tracked.

If a secret is accidentally pushed to GitHub:

1. Revoke or rotate the credential immediately.
2. Replace the exposed credential.
3. Remove the secret from the repository history if necessary.
4. Update the local `.env` configuration.
